## What is not a separate dollar rate

- The source inventory, forecast, CLI, CSV/JSON and Excel use shared pricing resolution. Exact Azure meters and captured Databricks regional price-card/calculator observations precede labelled reference estimates. Published source conflicts withhold a qualified quote. See [UNIT-COSTS.md](UNIT-COSTS.md).
- Jobs Light ($0.22/DBU), Clean Rooms ($50 per collaborator-day), and Data Processed ($0.02/GB) have stored Azure East US public observations only. Other placements remain unresolved; explicitly supplied customer rates and imported amounts retain their own provenance. Native prices live in the shared component registry rather than example monthly quantities.
- Jobs performance mode uses Jobs serverless. Agent Bricks, Agent Framework, Feature Serving, online tables, and the serverless GPU planning proxy reuse underlying services; they do not introduce an additional independently verified tariff.
- AI/BI dashboards and Genie SQL use serverless SQL. DBUs per refresh/question are usage assumptions. Genie user allowances, promotional factors, eligibility, and expiry are separate from the underlying list rate and must not be applied twice to billed imports.
- `ai_parse_document` uses a shared midpoint of the documented complexity band (10–15, 20–25, 60–65, 85–90 DBU per page). This is an approximation, not a guaranteed per-page tariff. The 50% promotion ended 2026-06-30 and is not applied.
- Foundation-model tokens and provisioned capacity are different billing dimensions. Provisioned consumption names the published 50-model-unit basis; GTE's conflicting provisioned observations remain unresolved in both the forecast and unit inventory. Additional models and external-provider token costs require labelled supplied assumptions.
- A model-serving scale-to-zero launch uses the shared 1 DBU planning conversion. The community source and unenforced two-launches-per-hour cap remain explicit limitations.
- Zerobus uses retained official US East price-card observations (AWS Premium $0.050/GB; AWS Enterprise and Azure Premium $0.064/GB). These GB rates are separate from generic DBU prices and do not establish availability in another cloud or region. GCP remains unresolved.
- Multi-statement transactions reuse the SQL warehouse charge. Lakehouse Real-Time regional ratios on other SKUs are labelled planning factors, not an additional charge or an exact regional tariff for those products.
- Delta Sharing, Private Link and NAT require route, endpoint, cloud, effective-date, and billing-scope checks. The official data-transfer tariff includes public charges that this calculator does not yet cover. Missing coverage means unresolved, not free networking or the absence of a public tariff.
- Learning concepts and products without an independently modeled rate point to underlying billable services. Their absent quote does not make connected compute, storage or networking free. Retired Standard meters are not an active forecast offering.
- Compliance's Azure per-DBU meters differ from the forecast's 10%/30% spend assumptions. Avoid adding a second product charge for the same usage.
- GCP Lakebase compute is unpriced. Cloud VM, object-storage, Search storage, regional proxies and unsupported dimensions retain their own evidence and limitations. See [COVERAGE.md](COVERAGE.md) and [RESEARCH.md](RESEARCH.md).
