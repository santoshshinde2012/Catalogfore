## What is not a separate dollar rate

- Jobs performance mode uses the Jobs serverless SKU. No mode multiplier is stored.
- Jobs Light is $0.22/DBU on Azure East US only. AWS and GCP stay $0.
- Clean Rooms is $50 per collaborator-day on Azure East US only.
- AI/BI Dashboards, Genie, and `ai_query` are placeholders at $0 so their warehouse or token spend is not counted twice.
- `ai_parse_document` is a published range (about 10–90 DBU per page on Microsoft Learn, fetched 2026-10-15), not a point rate.
- The model-serving launch charge meter is $0.07 per unit labeled `1`, not per hour. It is not multiplied.
- Data Processed is $0.02/GB on Azure East US and is not the internet-egress assumption.
- Standard tier meters still exist. The tier is retired, so the line is $0.
- Compliance meters ($0.10 and $0.15 per DBU on Azure East US) are not a second line. The portfolio add-on remains 10% or 30%.
- Lakehouse Real-Time regional prices are region factors on other SKUs, not an extra line.
- AWS and GCP $/DBU are the curated table in `data/sku-rates.json`. Databricks does not publish a price JSON. See [RESEARCH.md](RESEARCH.md).
- GCP Lakebase is unpriced and the Lakebase strategy contributes $0 on GCP.
