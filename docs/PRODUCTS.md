## What is not a separate dollar rate

- Jobs performance mode uses the Jobs serverless SKU. No mode multiplier is stored.
- Jobs Light is $0.22/DBU on Azure East US only. AWS and GCP stay $0.
- Clean Rooms is $50 per collaborator-day on Azure East US only.
- Agent Bricks, Agent Framework, Feature Serving, online tables, and serverless GPU reuse model serving, vector search, or training. The notes name the SKU. Serverless GPU uses the serving GPU table because AI_RUNTIME has no published GPU DBU/hour of its own.
- AI/BI dashboards and Genie SQL use serverless SQL. The DBU-per-refresh and DBU-per-question figures are assumptions, labeled in the editor. Genie One and Genie Agents user LLM usage is $0 through 2027-01-31. Genie Code bills DBU above 150 per user, with the documented 25% factor through that date.
- `ai_query` and Agent Evaluation are foundation-model tokens. Other foundation models and external models stay at $0 until you type DBU per million from the price page.
- `ai_parse_document` uses the midpoint of the published DBU-per-page band (10–15, 20–25, 60–65, 85–90) times the model-serving rate. The 50% promo ended 2026-06-30 and is not applied.
- A model-serving scale-to-zero launch is 1 DBU. The line does not enforce the two-launches-per-hour cap.
- Data Processed is $0.02/GB on Azure East US only. It is not the internet-egress assumption. AWS and GCP stay $0.
- Zerobus uses a secondary $/GB card (AWS Premium $0.050, AWS Enterprise and Azure $0.064). The example row is 100 GB. GCP is not priced. Official docs name a DBU SKU and do not print the dollar rate. The undated launch promotion is not applied. See [RESEARCH.md](RESEARCH.md).
- Multi-statement transactions became generally available on 2026-10-16. The announcement has no DBU rate or new SKU. That work is billed as the SQL warehouse already in this table.
- Delta Sharing and Private Link stay at $0. Same-region egress is not charged, and no 2026 page prints a dollar rate. Private Link hourly is billed on the marketing page and still “expected in the future” on the AWS cost doc. NAT has no Databricks rate.
- Databricks One, Marketplace, and Free Edition have no separate SKU. The line stays at $0 and says so.
- Standard tier meters still exist. The tier is retired, so the line is $0.
- Compliance meters ($0.10 and $0.15 per DBU on Azure East US) are not a second line. The portfolio add-on remains 10% or 30%.
- Lakehouse Real-Time regional prices are region factors on other SKUs, not an extra line.
- AWS and GCP $/DBU are the curated US East table times a Lakehouse Real-Time region factor. See [COVERAGE.md](COVERAGE.md) and [RESEARCH.md](RESEARCH.md).
- GCP Lakebase compute is unpriced. The workload row says so when the cloud is GCP.
